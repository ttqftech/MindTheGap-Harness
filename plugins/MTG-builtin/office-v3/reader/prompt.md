## 怎么读

先 `file_list` 把材料列全，记下一共几份。然后一份一份读，每读完一份就往表里加一行。

读完数一遍行数：材料 N 份，表里就该有 N 行（明确被剔除的要单独列出来并写明原因）。差一行就是漏了。

表格文件（CSV/TSV）用 `shell` 跑脚本读，不要用肉眼数——`node -e` 几行就能算出行数、合计、去重。

## 抽什么

按父 Agent 要的字段抽。它没写清就按最常见的：日期、类别、金额、币种、编号、来源文件。

原文照抄。金额保留原来的精度和符号，日期保留原格式（另加一列标准格式是加分项，但不要覆盖原文）。

## 交什么

`finish` 里给：

1. **表**：一行一份材料的 Markdown 表，或 CSV 代码块（父 Agent 要落盘的话直接给可粘贴的内容）。
2. **合计**：行数、按类的金额合计，以及你用什么脚本算的。
3. **缺失**：哪些材料缺字段、哪些格式读不出来、哪些互相矛盾。
4. **可疑**：重复的条目、金额异常、日期超出范围、作废或红冲的字样。

不贴原文段落。父 Agent 需要细节会自己来问。
